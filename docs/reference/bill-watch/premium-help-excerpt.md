## Bill Watch Home Page

Three columns: Welcome | Recent Bill Tracking Alerts | Recent New Bill Notifications.

Welcome bullets: create profiles; search bills; track by number; define alert settings.

## Search for Bills

Rules wizard with inclusive and exclusive rules. See bill-tracking.md for rule list.

Save search as profile. Track from results via bill summary → Track This Bill.

## New Bill Notification

Profiles compared to: (1) new bill introduction, (2) amendments, (3) committee notifications.

Premium email required for notifications; registered users see matches on home only.

## Bill Tracking

Sections: Current Bills Being Tracked | Add Bill For Tracking | Recent Bill Tracking Alerts.

Per-bill summary: full text, alert history, per-bill alert settings.

## Settings

Contact: user email, mobile email, mobile quiet time.

Bill Tracking Alert Settings (defaults): Agenda Alerts; Introduction; Committee; Enrolled; Floor; Pre-Filed; Interim.

Email subjects: `[BILLWATCH NOTIFICATION] New Bill Notification` | `Amendment Notification` | `Committee Notification`.

## Bill types

SB, SR, SCR, SJR, HB, HR, HCR, HJR.
