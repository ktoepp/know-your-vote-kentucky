# SMTP (transactional auth email) — Sender name + inbox "From" address
# -----------------------------------------------------------------------------
# Hosted Supabase (production / preview):
#   Dashboard → Project Settings → Authentication → SMTP Settings
#   - Enable custom SMTP and enter Host, Port, Username, Password from your provider.
#   - Sender email address: must be allowed by the provider (e.g. onboarding@your-domain.org).
#   - Sender name: shown as the display name in the recipient's inbox (e.g. "Know Your Vote Kentucky").
#   Save; auth emails (verify signup, password reset) use these settings.
#
# Local Supabase CLI (`supabase start`):
#   1. Add the variables below to a `.env` file in the REPO ROOT (same folder as `supabase/config.toml`).
#   2. Uncomment `[auth.email.smtp]` in `supabase/config.toml`.
#   3. Run `supabase stop` && `supabase start`.
#
# Resend (example): https://resend.com/docs/send-with-smtp
#   Host smtp.resend.com | Port 587 | User resend | Pass = API key (re_...)
#   Sender email must use a domain you verified in Resend.
#
# SUPABASE_SMTP_PASS=re_xxxxxxxx_or_app_password
# SUPABASE_SMTP_SENDER_EMAIL=auth@kyvky.com
# SUPABASE_SMTP_SENDER_NAME=Know Your Vote Kentucky

# Recommended mapping (matches typical #status-reports / #errors / #support webhooks):
#   SLACK_WEBHOOK_STATUS_REPORTS — cron/manual sync digests (routine runs)
#   SLACK_WEBHOOK_ERRORS — failed sync steps, health-check failures
#   SLACK_WEBHOOK_SUPPORT — optional copy of *critical* only: sync crashes + health failures
#                             (does not receive per-source row failures; those stay on ERRORS)
#
# Legacy names still work: SLACK_WEBHOOK_SYNC (digest), SLACK_WEBHOOK_ALERTS (errors),
# SLACK_WEBHOOK_URL (fallback for digest then errors chain).
#
# Digest posts for Vercel Cron syncs; set SLACK_SYNC_NOTIFY_MANUAL=true to also post manual runs.
# By default, status-reports digest only when something synced (itemsSynced > 0) or there were errors/skips.
# Set SLACK_SYNC_DIGEST_ALWAYS=true for a digest on every cron run (heartbeat).
# Smoke-test webhooks: npm run slack:smoke-test — or GET /api/cron/slack-test with Bearer auth.
#
# GitHub → Slack (commits / PRs / merges): add repo secret SLACK_WEBHOOK_GITHUB (Incoming Webhook URL).
